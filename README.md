# HIGHFLY NEXT CORE

Base de desarrollo de HIGHFLY sobre World of ClaudeCraft `release/v0.39.0`.

Objetivo actual: conservar ClaudeCraft por defecto, modificar solo lo necesario y generar APK Android offline para pruebas reales en Samsung S23 Ultra.

El código fuente upstream no se copia completo en este repositorio: el workflow de CI clona la versión fijada de ClaudeCraft y aplica la capa HIGHFLY durante el build.
